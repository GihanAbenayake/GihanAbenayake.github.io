My time working with Unreal Engine has led to a range of smaller projects being worked on to familiarise myself with the engine and its capabilities. A few of which I will be listing down below

A Typical Horror Game (ATHG)

A Typical Horror Game, is a project that I started to work on to familiarise myself with Unreal Engine 5's systems and to learn more about how to create a horror game. The project is a first person horror game, where the player is tasked with escaping a haunted house. The game is inspired by the likes of Phasmophobia and Outlast in terms of its completed atmosphere and gameplay mechanics.

I've also taken inspiration from Fears to Fathom: Home Alone in terms of its initial House Invasion style theme.

The games main, planned game loop is:

Awaken in the House -> Complete Objectives (Such as Locking doors and windows, doing simple logic puzzles etc) -> Hide from the Monster/s -> Survive the Day and repeat



The game was made to focus on experiment with atmosphere and the implementation of smarter monster AI, with the current iteration able to identify windows, and peek through them, as well as undoing locks and opening them to gain entry inside. Currently, only one monster is implemented, but their more passive nature is planned to be contrasted with a more aggressive, though shorter lasting monster as well.

As now, an interaction system using Line Traces allows for the player to perform actions, such as opening and closing doors or locking windows shut to prevent entry. All animations are done in game with the use of Unreal Engine's Timelines and linear interpolation functions, to provide easy modification and maintanence, rather then having to modify the animations in an external program and then reimporting them.

An objective system is also complete, with static objectives as of now, but the desire to make them randomised based on the day, four have been implemented so far, but a larger variety is planned for the future.

The game is still in development, but I am excited to see where it goes in the future, with plenty of plans in place, such as more monsters, more interaction options and more replayability with a rogue-like scoring system to be implemented.

Logistico

Logistico, is a game inspired by the likes of Workers & Resources: Soviet Republic (W&R), in particular, its unique approach to construction and logistics.

The game uses a setting called Realistic Mode, which, requires a player to not only designate a building to be built, but to also store and ferry resources via vehicles to the build site. While a slow process, it has peaked my interest in the logistics management area, and I decided to pursue making a similar concept in Unreal Engine.

Logistico's aim, is to focus more on the construction aspect, rather then where W&R focuses on the management of a town. With the aim to start in debt, and work your way out by assisting in the completion of contracts and in turn, building up a successsful logistics and construction company.

Logistico's main loop is as such:

Select a Contract -> Deliver the Required Materials ->Deliver the Required Vehicles -> Begin and monitor construction -> On completion gain Credits -> Use those Credits to finance the purchase of Materials to build industry Or Purchase Vehicles to assist in speeding up the construction process or allowing new, more profitable buildings to be made -> Repeat


While working on the project, I've learnt quite a bit about how to use masked materials, as well as learning about procedural generation for terrain using noise textures to simulate height maps for voxel based terrain, similar to Minecrafts own terrain generation. User Interface design has also been something I've delved into with the project, and I'm excited to continue working on it.
